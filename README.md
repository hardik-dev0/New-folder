# 🎮 CLI Number Guessing Showdown

A fun and interactive Command-Line Interface (CLI) guessing game built using Python.

## 🚀 Features
- **Smart Hints:** Alerts the player whether their guess is too high or too low.
- **Scoring System:** Dynamic score calculation based on remaining attempts.
- **Input Validation:** Handles invalid inputs cleanly without crashing.

## 🛠️ Tech Stack
- **Language:** Python 3
- **Tools:** VS Code, Git & GitHub

## 🎯 How to Run
1. Make sure Python is installed on your machine.
2. Run the script via terminal:
   ```bash
   python main.py
